# Kunal Kumar — Frontend Developer Portfolio

A modern, high-performance personal portfolio website crafted with a **Violet Dusk** atmospheric theme, glassmorphism aesthetics, scroll-driven micro-interactions, and responsive design.

Live Demo: [kunalportfolio-01.netlify.app](https://kunalportfolio-01.netlify.app/)

---

## ✨ Features

- **Violet Dusk Theme**:
  - Deep velvet twilight backgrounds (`#090514` & `#130A24`) with glowing violet, lavender, and dusk rose accents.
  - Custom glass cards with backdrop blur, subtle twilight borders, and gradient highlights.
- **Hero Developer Studio**:
  - Interactive glassmorphic code editor window with file tabs (`developer.js`, `skills.json`, `terminal.sh`).
  - Interactive code copy button, line numbering, and floating tech badge chips (`React`, `JavaScript`, `CSS3`, `UI/UX`).
  - 3D perspective mouse tilt (`useTiltEffect`).
- **Micro-Interactions & Scroll Animations**:
  - **Scroll Progress Bar**: Glowing violet-dusk gradient bar along the navigation tracking reading progress.
  - **Floating Scroll Companion**: Circular SVG progress ring indicating exact scroll percentage with smooth back-to-top interaction.
  - **Staggered Scroll Reveals**: Sections, cards, and milestones cascade in smoothly as you scroll.
  - **Parallax Background**: Atmospheric violet and rose dusk orbs that translate with scroll depth.
- **Interactive Sections**:
  - **Hero**: Introduction, social links, call-to-actions, and interactive developer studio window.
  - **About**: Profile card, university details, and stats counter.
  - **Skills**: Categorized skill cards across Frontend, Programming, and Beyond the Stack.
  - **Projects**: Showcase featuring interactive mock previews, technology tags, and source/demo links.
  - **Journey (Education)**: Academic timeline with active status indicator.
  - **Contact**: Status indicator, direct copy-to-clipboard email action, interactive contact form with validation, and social links.
  - **Footer**: Brand statement, quick jump links, and smooth back-to-top navigation.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vite.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG brand glyphs
- **Linter**: [Oxlint](https://oxc.rs/)
- **Typography**: Inter, Space Grotesk, JetBrains Mono

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Navigate to project directory
cd fe

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
# Lint check
npm run lint

# Build for production
npm run build

# Preview build locally
npm run preview
```
